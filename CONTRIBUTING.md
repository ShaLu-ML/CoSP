# Contributing

Use synthetic examples in issues, tests and pull requests. Do not upload EEG, participant metadata, clinical images, detailed experiment outputs, private configuration, caches or checkpoints.

For a change, describe its purpose and provide a focused test. Keep scientific-method changes explicit, including changes to preprocessing, splits, losses, thresholds or metric definitions. Run the source checks and helper tests in the [README](README.md), plus any tests relevant to the modified component.

Keep new dependencies and their licenses documented. Contributions to this software are provided under the repository's [MIT License](LICENSE); retain applicable third-party notices.
